# Локальная среда разработки и хранения капсулы

Правило: OWNER-LOCAL-FIRST-2026-10-30. Утверждено Владельцем 30.10.2026.

- DOMKAT — основная рабочая машина.
- Рабочий каталог проекта: D:\Dev\telegram-receiver.
- Капсула менеджера хранится вместе с проектом на ветке состояния main.
- Авторитетная ветка продукта: main. Не заменять её веткой менеджера.
- Если ветка состояния отдельная, использовать связанное рабочее дерево .worktrees/main.
- Редактирование, тестирование, сборку и актуализацию капсулы выполнять преимущественно локально.
- GitHub — удалённая история версий, синхронизация и резервное восстановление. Прямая разработка через GitHub допустима при необходимости или по указанию Владельца.
- При недоступности DOMKAT восстанавливаться из последней подтверждённой версии GitHub и сообщать о вероятных неопубликованных локальных изменениях.
- Перед изменениями проверить идентичность репозитория, верные ветки, состояние рабочего дерева, целостность капсулы и актуальный remote.
- Перед push выполнить fetch и сверку. Не делать force push, слепой reset, rebase или потерю незафиксированных изменений.
- Если изменены защищённые данные менеджера, обновить маркер целостности в его установленном формате и проверить согласованность поколения.
- После push сверить SHA удалённой ветки и содержимое публикации.
- Не публиковать секреты, ключи, пароли и приватные пользовательские данные.
- Перемена рабочей машины не передаёт никаких дополнительных полномочий и не меняет обязательства, историю, мандат и границы ответственности.
